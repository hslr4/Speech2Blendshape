From [FaceDiffuser](https://github.com/uuembodiedsocialai/FaceDiffuser)

Download the BEAT dataset from [here](https://pantomatrix.github.io/BEAT/) then use the `beat_split.py` script to create the training sequences.

FaceDiffuser repo also provides a blender project `BeatVisualise.blend` which can be used to render the facial motion sequences.
